# Requisitos


Este documento detalha os requisitos do site a ser desenvolvido.

## BackLog de Produto



*

* O professor não quer Login
* Qualquer pessoa pode cadastrar
* Tela que lista animais / Donos
* Tela de Cadastro
* Funcional
* Aula diagrama
* O site deve possuir os seguintes requisitos:
● Cadastro de clientes (tutores) e seus pets;
● Especificação de características dos pets como espécie, raça, cor,
peso;
● Histórico exames e enfermidades;
● Receituário (e.g. anotação de remédios e tratamentos prescritos).
